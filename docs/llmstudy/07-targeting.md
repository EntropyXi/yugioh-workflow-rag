# 07 — 取对象（Targeting）规则

> **撰写日期**：2026-07-28
> **来源**：P0 官方规则书 + P2 `ocg-rule`
> **对应项目**：`declared_targets` 字段、`target_legality` 的 failed_check

---

## 1. 什么算"取对象"

**取对象（Targeting）** 是指效果在发动时选择特定的卡作为效果的处理目标。

### 1.1 如何判断是否取对象

日文原文判断方法——看效果文本：

| 文本特征 | 是否取对象 |
|---|---|
| 「○○を対象として発動できる」（以○○为对象才能发动） | **是** |
| 「○○を対象とする」（以○○为对象） | **是** |
| 「選ぶ」（选择） | **通常不取对象** |
| 没有上述字样 | 一般不取对象 |

> 简中官方文本同样遵循此规则——"以……为对象"就是取对象，"选……"不取对象。

### 1.2 取对象 vs 不取对象

| | 取对象 | 不取对象（处理时选择） |
|---|---|---|
| 选择时机 | **发动时** | **效果处理时** |
| 对方能否在连锁中确认 | 是（公开信息） | 否（处理时才决定） |
| 不被取对象的效果能避免吗 | 能 | 不能 |
| 适用前对象消失的处理 | 效果不适用 | 处理时才选，不存在消失问题 |

## 2. 取对象的时间线

### 2.1 发动时取对象（标准流程）

```
1. 宣言发动
2. 支付 cost
3. 选择对象（此时对方看到选择了什么）
4. 确认连锁
5. 效果处理：检查对象是否仍然合法
6. 如合法 → 处理效果
   如不合法 → 效果不适用（"不発"）
```

### 2.2 对象的连续性

对象一旦被选定，效果处理时会再次检查对象是否合法：
- 对象变成里侧 → 取决于效果文本是否要求表侧
- 对象离开场上 → 通常效果不适用
- 对象从怪兽区域移到魔陷区域 → 不再是"场上的怪兽"

> **case_025**：墓穴指名者的对象在效果处理时离开墓地 → `target_legality` 不合法

```json

  "column_index": 3

```

`declared_targets` 是 `attempted_operation` 中的可选数组，用于记录发动时声明的对象。

## 4. 不取对象的"选择"效果

部分效果文本使用「選ぶ」（选择）而非「対象」：

例如：「地帝 格兰玛格」—— "把场上盖放的 1 张卡破坏"
- 效果处理时才选择哪张卡
- 对方不能在连锁中通过移除潜在目标来保护
- 不受取对象抗性影响

本项目 Schema 中用两个 effect_features 区分：
- `destroy_target` — 发动时取对象并破坏
- `choose_1_card_on_field_on_resolution` + `destroy_chosen_card` — 处理时选择并破坏

## 5. 取对象相关裁定案例

| 场景 | case | 裁定 |
|---|---|---|
| 灰流丽取不取对象？ | case_001 | 不取 — 灰流丽的效果是"对方发动包含……的效果时才能发动"，不是以某张卡为对象 |
| 光之护封剑可成为回手对象 | case_014 | 取对象合法 |
| 墓穴指名者的对象离场 | case_025 | `target_legality` — 处理时对象不在墓地 |
| 食魂窃蛋龙对象被替代破坏 | case_034 | 涉及失落世界的替代破坏机制 |
| 大搜捕对象同连锁变里侧 | case_020 | 对象变成里侧后的处理 |
| 暗之咒缚降攻后选择对象 | case_048 | 对象合法性的时点问题 |
