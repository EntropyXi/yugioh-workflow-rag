## 规则核心术语

| 简体中文 | 日文 | 英文 | 说明 |
|---|---|---|---|
| 连锁 | チェーン | Chain | 多个效果连续发动 |
| 咒文速度 | スペルスピード | Spell Speed | 1-3，决定连锁优先权 |
| 优先权 | 優先権 | Priority | 发动卡或推进回合的权利 |
| 取对象 | 対象をとる | Target | 发动时选择特定卡 |
| 不取对象 | 対象をとらない | Non-targeting | 处理时才选择 |
| Cost/代价 | コスト | Cost | 发动时支付的代价 |
| 解放 | リリース | Tribute | 将怪兽送去墓地（一种 cost） |
| 苏生限制 | 蘇生制限 | Rebirth Restriction | 特殊召唤怪兽需先正规出场 |
| 召唤限制 | 召喚制限 | Summon Restriction | 怪兽自带的召唤条件 |
| 正规手续 | 正規の手順 | Proper Summon | 满足条款的特殊召唤 |
| 不受影响 | 効果を受けない | Unaffected | 免疫其他卡的效果 |
| 替代破坏 | 破壊の代替 | Destroy Replacement | 用其他卡代替被破坏 |
| 卷回 | 巻き戻し | Replay | 攻击宣言后对方怪兽变化时重新选择 |
| 伤害步骤 | ダメージステップ | Damage Step | 战斗阶段中的伤害计算环节 |
