# 01 — 卡牌类型体系

> **撰写日期**：2026-07-28
> **来源**：P0 KONAMI 官方规则书 + P2 `ocg-rule.readthedocs.io`
> **对应项目 case**：全部 58 条 case 的 `card_type` / `monster_type` / `spell_type` / `trap_type` 字段

---

## 1. 三大基础类型

游戏王卡片在规则上分为三大类：

```
怪兽卡 (Monster Card) ─── 橙色/蓝色/白色/黑色/绿色等底色
魔法卡 (Spell Card)    ─── 绿色底色，卡名右侧有「魔」标识
陷阱卡 (Trap Card)     ─── 紫色底色，卡名右侧有「罠」标识
```

每种在场上放置的位置和方式不同：
- **怪兽卡**：放置在怪兽区域（Main Monster Zone 或 Extra Monster Zone）
- **魔法卡**：放置在魔法&陷阱区域（或场地区域/灵摆区域）
- **陷阱卡**：放置在魔法&陷阱区域（盖放后下回合才能发动）

## 2. 怪兽卡（Monster Card）

### 2.1 怪兽卡的属性字段

每张怪兽卡包含以下核心属性（对应本项目 Schema 中的 `card` 对象）：

| 字段 | 本项目 Schema 字段 | 说明 |
|---|---|---|
| 卡名 | `name` | 怪兽名称 |
| 属性 | `attribute` | 地/水/炎/风/光/暗/神 |
| 种族 | `race` | 龙/战士/魔法师/机械等 25 种族之一 |
| 等级/阶级/LINK | — | 怪兽的等级（星数）或 Link 值 |
| 攻击力/守备力 | — | ATK / DEF |
| 种类/能力 | `monster_type` | 通常/效果/融合/仪式/同调/超量/灵摆/连接 |
| 表示形式 | `status` + `position` | `face_up`/`face_down` + `attack`/`defense` |

### 2.2 怪兽种类（Monster Type）枚举

本项目 Schema 中 `monster_type` 的完整枚举：

| 枚举值 | 分类 | 说明 | 对应 case 示例 |
|---|---|---|---|
| `normal` | 通常怪兽 | 无效果的黄色怪兽。灵摆通常怪兽也属于此类 | — |
| `effect` | 效果怪兽 | 有效果的橙色怪兽（占绝大多数） | 灰流丽 (case_001)、增殖的 G (case_006) |
| `fusion` | 融合怪兽 | 紫色卡，从 EX 卡组融合召唤 | 赫焉龙 (case_005) |
| `ritual` | 仪式怪兽 | 蓝色卡，通过仪式魔法召唤 | — |
| `synchro` | 同调怪兽 | 白色卡，调整+非调整同调召唤 | — |
| `xyz` | 超量怪兽 | 黑色卡，叠放召唤（RANK 代替 LV） | 编号38 (case_026) |
| `link` | 连接怪兽 | 深蓝色卡，连接召唤（LINK 值代替 DEF） | S:P 小夜骑士 (case_003) |
| `toon` | 卡通怪兽 | 特殊分类，有卡通世界依赖 | 卡通怪兽 (case_040/043) |
| `pendulum` | 灵摆怪兽 | 半绿半橙，可当怪兽也可以当魔法卡发动 | case_024, case_027 |

> **注意**：Schema 中的 `monster_type` 捕捉的是怪兽的召唤种类标签。一张融合怪兽如果同时是效果怪兽，其 `card_type` = `monster`，`monster_type` = `fusion`，效果文本另行描述。

### 2.3 效果怪兽的效果分类（OCG 规则层面）

OCG 规则将怪兽效果分为 **5 类**：

| 分类 | 日文 | 说明 | 入连锁？ |
|---|---|---|---|
| **起动效果** | 起動効果 | 自己主要阶段主动发动（"1 回合 1 次，……才能发动"） | 是 |
| **诱发效果** | 誘発効果 | 满足条件时自动发动（"……的场合/时发动"） | 是 |
| **诱发即时效果** | 誘発即時効果 | 对方回合也能发动的效果（"对方回合也能发动"），咒文速度 2 | 是 |
| **永续效果** | 永続効果 | 只要在场就持续适用，不发动（如 Skill Drain） | 否 |
| **无种类效果** | 分類されない効果 | 不属于以上四类（如"这张卡不能通常召唤"、规则文本） | 否 |

> 本项目 58 条 case 中，大量涉及起动效果和诱发效果的发动合法性判断。

## 3. 魔法卡（Spell Card）

### 3.1 魔法卡的子类

本项目 Schema 中 `spell_type` 的枚举：

| 枚举值 | 图标标识 | 咒文速度 | 说明 | 对应 case 示例 |
|---|---|---|---|---|
| `normal_spell` | 无 | 1 | 主要阶段发动，处理后送墓 | — |
| `quick_play_spell` | 速攻 | 2 | 对方回合也能发动，盖放后下回合可用 | 墓穴指名者 (case_025) |
| `continuous_spell` | 永 | 1 | 发动后留在场上持续适用 | 联合机库 (case_011) |
| `equip_spell` | 装 | 1 | 装备给怪兽，持续适用 | 大搜捕 (case_020) |
| `field_spell` | 场 | 1 | 放置在场地区域（不是魔陷区） | 完美卡通世界 (case_040) |
| `ritual_spell` | 仪 | 1 | 用于仪式召唤 | — |

### 3.2 魔法卡的发动限制

- 通常/装备/永续/场地/仪式魔法：只能在**自己主要阶段**发动（咒文速度 1）
- 速攻魔法：可以在**任意阶段**发动（咒文速度 2），盖放的速攻魔法在盖放回合不能发动
- 魔法卡的一般发动流程：从手牌放到魔陷区 → 支付 cost → 选择对象 → 发动 → 效果处理

## 4. 陷阱卡（Trap Card）

### 4.1 陷阱卡的子类

| 枚举值 | 图标标识 | 咒文速度 | 说明 | 对应 case 示例 |
|---|---|---|---|---|
| `normal_trap` | 无 | 2 | 盖放后下回合可发动，处理后送墓 | 无限泡影 (case_002)、神之通告 (case_004) |
| `continuous_trap` | 永 | 2 | 发动后留在场上持续适用 | 技能抽取 (case_015, case_018) |
| `counter_trap` | 反 | 3 | 最高咒文速度，只能被反击陷阱连锁 | 神之警告 (case_023) |

### 4.2 陷阱卡的特殊规则

- **必须盖放**：陷阱卡必须先盖放（Set）到魔陷区，盖放回合不能发动
- **反击陷阱**：咒文速度 3，只有反击陷阱能连锁反击陷阱
- **陷阱怪兽**：部分永续陷阱卡发动后可以变成怪兽特殊召唤到怪兽区域（如"阿匹卜之化神"），此时原魔陷区域被释放可用

## 5. 灵摆怪兽（Pendulum Monster）的特殊性

灵摆怪兽是独特的"半怪兽半魔法"类型：
- 可以作为**怪兽**通常召唤/特殊召唤到怪兽区域
- 也可以作为**魔法卡**放置在灵摆区域（魔陷区的最左和最右）
- 在灵摆区域时，使用其灵摆效果（不是怪兽效果）
- 场上被破坏时不去墓地，而是**表侧表示加入额外卡组**

> 本项目 case_024 涉及灵摆怪兽送墓 cost 的问题——场上灵摆怪兽无法送墓，因此不能支付送墓 cost。

## 6. 与本项目的对应关系

项目数据中的卡片表示分为两种上下文：

### 场上卡片（`card` 对象 in `field` / `current_chain_links`）
```json
{
  "name": "灰流丽",
  "status": "face_up",
  "card_type": "monster",
  "monster_type": "effect",
  "controller": "opponent"
}
```

### 对象声明（`target` 对象）
```json
{
  "card": "烙印之气炎",
  "controller": "opponent",
  "location": "spell_trap_zone",
  "zone": "s2",
  "status": "face_up",
  "card_type": "spell"
}
```

注意 `card_type` 只分三大类（`monster`/`spell`/`trap`），细分类用 `monster_type`/`spell_type`/`trap_type`。
