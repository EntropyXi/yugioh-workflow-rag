# 09 — 持续效果 vs 发动效果

> **撰写日期**：2026-07-28
> **来源**：P2 `ocg-rule` + P1 yugipedia
> **对应项目**：`failed_check: effect_resolution_rule`、case_015/018/045（涉及 Skill Drain/持续效果相关）

---

## 1. 持续效果（Continuous Effect）

### 1.1 定义

**不入连锁、只要怪兽在场就持续适用**的效果。没有发动时机，不需要宣言。

### 1.2 典型例子

| 卡片 | 持续效果 | 类型 |
|---|---|---|
| 技能抽取 (Skill Drain) | "场上的表侧表示怪兽的效果无效化" | 陷阱的永续效果类 |
| 王家长眠之谷 (Necrovalley) | "涉及墓地的卡的效果无效化" | 场地的效果 |
| 米德拉什 (El Shaddoll Winda) | "双方 1 回合只能有 1 次特殊召唤" | 怪兽的永续效果 |
| 电子界到临者 (The Arrival Cyberse) | "不受其他卡的效果影响" | 怪兽的永续效果 |

### 1.3 持续效果的规则特性

- **不发动** → 不能被"魔宫的贿赂"等无效发动的卡连锁
- **只要满足条件就立即适用** → 离场时立即不适用
- **被无效时**（如 Skill Drain 适用中）→ 永续效果不适用
- **适用优先级**：先适用的持续效果先影响场面

---

## 2. "不受效果影响" (Unaffected)

### 2.1 核心概念

部分怪兽有"不受其他卡的效果影响"的能力。这不等于"不能被取对象"。

| 文本 | 保护范围 | 能否取对象 |
|---|---|---|
| "不受其他卡的效果影响" | 所有效果（取对象+不取对象） | 不能取对象（因为取对象本身是效果的一部分） |
| "不会成为效果的对象" | 仅取对象效果 | 不能取对象，但可以被不取对象的效果影响 |
| "不会被效果破坏" | 仅破坏效果 | 可以取对象，也可以被除外/送墓 |

### 2.2 Unaffected 怪兽与 Skill Drain

- **已经适用 Skill Drain** → unaffected 怪兽出场 → 谁的效果适用？
  - 新出场的怪兽的效果在后适用 → 不受 Skill Drain 影响
- **Unaffected 怪兽先在场** → Skill Drain 后适用？
  - Skill Drain 不影响它 → 永续效果仍在 → unaffected

> 这是 case_015 的核心：伤害步骤中龙骑兵团的效果不受 Skill Drain 影响。如果 unaffected 怪兽在场，Skill Drain 对它无效。

---

## 3. 持续效果与其他规则的交互

### 3.1 持续效果 vs 发动效果

"不受其他卡的效果影响"的怪兽：
- 不能成为取对象的发动效果的目标
- 不适用不取对象的发动效果的处理
- **但**仍然受规则约束（不能被效果破坏 ≠ 不能被战斗破坏）

### 3.2 作用于怪兽 vs 作用于玩家的限制

这是非常重要的区分——直接影响 case_003 的裁定：

| 限制类型 | effect_scope | 特性 |
|---|---|---|
| 作用于怪兽 | `monster` | "不受效果影响"的怪兽可以绕过 |
| 作用于玩家 | `player` | "不受效果影响"不能绕过 |

**case_003 场景**：
- S:P 小夜骑士的效果："自己怪兽不能直接攻击"
- 如果建模为 `effect_scope: "monster"` → 全抗怪兽（不受影响）可以绕过
- 如果建模为 `effect_scope: "player"` → 任何怪兽都不能直接攻击
- **正解**：S:P 的效果是作用于怪兽的 → effect_scope: monster → 全抗怪兽可以直接攻击

### 3.3 持续适用 vs 已经发动的效果

- Skill Drain 适用中发动的效果：处理时效果无效
- Skill Drain 适用前已成功发动的效果：已经适用的部分不回溯

> **case_018**：颠茄歌后在 Skill Drain 适用中发动效果，处理时效果无效。

---

## 4. 永续魔法/陷阱的效果

### 4.1 与怪兽永续效果的相似性

永续魔法/陷阱在场时持续适用的效果：
- 卡从场上离开 → 效果立即不适用
- 卡被无效（如"旋风"破坏前适用）→ 效果立即不适用
- "发动"本身可以连锁（因为是卡的发动），但持续适用的部分不发动

### 4.2 永续陷阱怪兽

陷阱卡发动后变成怪兽特殊召唤：
- 在怪兽区域时：当作怪兽，怪兽相关的效果影响它
- 在魔陷区域时：当作陷阱卡
- 2020.04 规则：变成怪兽后释放原来魔陷区域

## 5. 关键裁定案例

| 场景 | case | 核心裁定 |
|---|---|---|
| Skill Drain 下龙骑兵团发动效果 | case_015 | legal — 伤害步骤中适用的效果不受 Skill Drain 影响 |
| Skill Drain 下颠茄歌后的处理 | case_018 | illegal — 持续无效已适用，效果处理无效 |
| S:P 限制下全抗怪兽的直接攻击 | case_003 | legal — 怪兽限定的限制，unaffected 怪兽可绕过 |
| 白龙忍者保护光之护封剑？ | case_045 | legal — 自毁不是"对方的效果"，白龙忍者不保护 |
